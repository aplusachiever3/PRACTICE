# 随笔记智能机器 V2.0

一个简单的个人记录工具，把生活、学习、工作和灵感放在同一个地方。无需账号、API 或构建步骤，打开网页即可使用。

## V2.0 功能

- **快速记录**：在首页写下一句话即可保存；电脑可用 Ctrl+Enter（Mac 可用 Command+Enter）快速提交。
- **自动分类建议**：根据文字中的关键词建议归入待办、工作、学习、生活、灵感或随笔。它是本地规则，不是云端 AI；分类可在详细编辑里修改。
- **一处搜索**：搜索标题、正文、标签和分类。
- **常用视图**：全部、今天、待办、重要、灵感、工作、学习、生活和归档。
- **待办管理**：标记完成、设置可选截止日期。
- **编辑整理**：修改标题、正文、分类、标签，标记重要或归档，也可删除记录。
- **备份迁移**：导出 JSON 备份，之后可在另一台设备手动导入。

## 本机保存与隐私

记录保存在当前浏览器的 `localStorage` 中，不会自动上传到 GitHub，也不会自动同步到手机或其他电脑。

请注意：
- **同一设备、同一浏览器**通常才能直接看到同一份记录。
- 清除浏览器数据、使用无痕模式或更换浏览器，可能导致记录无法读取。
- 建议定期点击“导出备份”，并把 JSON 文件保存在自己掌控的位置。
- 换设备时，在旧设备导出备份，再在新设备打开网页并导入。
- 这不是加密保险箱；请勿把密码、银行卡资料等高度敏感信息存入其中。

## 启用 GitHub Pages

1. 打开仓库 Settings。
2. 进入 Pages。
3. 在 Build and deployment 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/(root))，点击 Save。
5. 等待 GitHub Pages 部署完成后，打开： https://aplusachiever3.github.io/PRACTICE/
